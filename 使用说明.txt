LibreTV 纯前端网页版 · 使用说明
==================================

一、这是什么
基于 GitHub bestZwei/LibreTV（LibreTV-Next）重构的纯前端影视聚合网页。
不需要服务器，搜索、点播、直播、播放全部在浏览器里完成，
数据（源配置/历史/进度/收藏）只保存在本机 IndexedDB。

二、怎么在 iPhone / iPad 上用
方式 A：直接把 libretv-ios.html 通过"文件"App 或 AirDrop 传到手机，
在"文件"中打开，点右上角分享 → 用 Safari 打开。
方式 B（推荐，体验最好）：把整个文件夹上传到任意静态托管（GitHub Pages、
Cloudflare Pages、Vercel 静态、对象存储等），用 Safari 打开网址后：
  分享 → 添加到主屏幕，即可像 App 一样全屏使用。
（托管后 manifest.json / sw.js / icon-*.png 会自动生效，支持离线缓存）

三、内置数据源（开箱即用）
点播：莱兹资源、暴风资源、非凡资源（Apple CMS 采集接口）
直播：中文直播 iptv-org（149 个公开中文频道，成人频道默认过滤）
说明：预置源为第三方公开接口，可能随时失效；失效时在 设置 → 点播源/直播源 删除或
替换，也可用"导入 TVBOX / 订阅配置"批量添加自己的源。

四、常用功能
- 首页：继续观看（带进度续播）、我的收藏、最近更新
- 搜索：多源并行聚合搜索，同名影片自动合并成一张卡片（多点来源切换）
- 播放：iOS 原生 HLS 播放、倍速（0.5~3x）、长按画面 0.6 秒切 3 倍速、
  自动连播下一集、进度精确到秒记忆、选集面板
- 直播：M3U 频道分组浏览、频道搜索、频道收藏、HLS/FLV 播放、EPG 节目单（需源带 xml 版 EPG）
- 设置：源管理（增删改/启停/测活）、TVBOX 配置导入、跨域代理模式、
  成人内容过滤、主题切换、配置导出/导入

五、网络与代理
部分采集站接口不带跨域头，浏览器直连会被拦截。网页默认"直连 → 失败自动走代理"，
内置 4 个公共 CORS 代理候选；如果都不通，到 设置 → CORS 代理模板 换成可用的代理
（模板里 {url} 会被替换为目标地址）。直播 m3u8 播放不受跨域限制（视频标签直连）。

六、已知限制（纯前端版的取舍）
1. 官方版的服务端聚合/直播长连接代理、访问密码、多页搜索抓取等功能不在本版
2. 个别源的"网页解析线路"（非直链 m3u8）无法在浏览器端解析
3. gzip 压缩的 EPG 无法解压，请使用 xml 格式 EPG
4. 公共 CORS 代理与预置采集站随时可能失效，属于第三方环境因素

七、免责声明
本项目仅聚合第三方公开接口与播放列表，不存储、不制作任何内容，内容合法性由数据源负责。
